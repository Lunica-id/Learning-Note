### User Enumeration

例えばログイン画面において、ユーザー名が違う場合は
`Invalid username or password`
と出るのに、パスワードが違う場合は
`Incorrect password`
と出る場合、そのユーザーが登録されているということが攻撃者に知られてしまう
これにより、攻撃者が調べなければいけないことが一つ減る
